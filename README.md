A tiered dip-reversion bot that trades Coinbase Wrapped BTC (cbBTC) minute by minute on 1-minute on-chain bars. It buys significant dips below a 90-bar moving average in two tiers (50% at -1.5%, the rest 1% lower), then exits on a trailing stop, a +3% target, a -2% stop-loss, or a 180-bar time limit. Local dev grade: +$34.01 net PnL on the frozen 24h dev window (6 trades, 100% win rate).

## Run it
